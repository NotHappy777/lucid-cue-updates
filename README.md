# 清醒提示

Android 本地清醒练习与定时提示工具。本仓库仅发布安装包、更新清单与版本说明，不存放应用源码或用户记录。

[下载 1.2.0 APK](https://github.com/NotHappy777/lucid-cue-updates/releases/download/v1.2.0/lucid-cue-1.2.0.apk) · [查看最新版本](https://github.com/NotHappy777/lucid-cue-updates/releases/latest)

已有应用请直接覆盖安装，不要先卸载。Android 会要求你确认安装，首次可能需要允许下载来源安装应用。

安装 1.2.0 后，可在「提醒 → 声音与设置 → 应用更新」中检查、下载并安装后续版本，无需 USB。更新需要网络能够访问 GitHub；不会上传梦境、日程或备份记录。

「夜间重复」可设每组 1–10 次，间隔 10、20、30 或 60 秒。旧安装升级保留单次设置，白天提示和训练中的每次短音不套用夜间重复。播放通知中可随时停止当前组。

软件完成播放不等于人实际听到，也不代表识别到睡眠阶段或保证出现清醒梦。
